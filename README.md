# Misión RoboTech-1

Bienvenido al sistema de preparación de la misión RoboTech-1.

Durante este taller aprenderás a:

- Orientarte mediante la terminal.
- Crear, copiar y eliminar archivos y directorios.
- Examinar registros de telemetría.
- Buscar advertencias en los datos.
- Utilizar variables de entorno.
- Guardar los cambios mediante Git.

## Objetivo

Analiza el archivo `telemetria.log`, prepara la documentación de la misión y crea un informe final antes del lanzamiento.

## Normas de la misión

1. Trabaja dentro de este repositorio.
2. Lee cuidadosamente cada objetivo antes de ejecutar comandos.
3. Consulta la cheatsheet cuando necesites ayuda.
4. Comprueba el resultado de cada comando.
5. No tengas miedo de equivocarte: corregir errores forma parte de la misión.

¡Buena suerte, comandante!
